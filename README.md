# Bootstrap Modal: исследование жизненного цикла

Работающий демонстрационный проект для исследования внутреннего устройства **Bootstrap 5.3.8**.

**Автор:** Саморуков Геннадий

- Репозиторий библиотеки: [twbs/bootstrap](https://github.com/twbs/bootstrap).
- Точная исследуемая версия: [v5.3.8](https://github.com/twbs/bootstrap/tree/v5.3.8).
- Механизм: открытие и закрытие Modal, события, композиция Backdrop / FocusTrap / ScrollBarHelper и согласование с CSS-переходами.
- Язык: JavaScript. Страница использует HTML/CSS и оригинальный модуль Bootstrap без React и jQuery.

## Запуск

Установите Node.js 22 или новее. В терминале перейдите в корень этого проекта — папку, содержащую package.json:

```sh
npm ci
npm run dev
```

Откройте (http://127.0.0.1:5174). Остановка сервера — Ctrl+C.
Если зависимости уже установлены, достаточно `npm run dev`.
Порт 5174 должен быть свободен: одновременно запускайте только один экземпляр этого демо.

## Что показывает приложение

- Порядок show / shown / hide / hidden и разницу между возвратом show() и завершением открытия.
- Поведение с анимацией и без неё.
- Отмену show / hide через preventDefault и отдельное событие hidePrevented.
- Настройки keyboard, focus и backdrop, удержание фокуса, восстановление прокрутки.
- Открытие через JavaScript API и HTML Data API.
- Игнорирование hide() во время открытия.
- Получение существующего экземпляра и очистку закрытого компонента через dispose().

Журнал записывает события и снимки состояния. Внутренние поля Bootstrap читаются только для учебного наблюдения. Сам компонент импортируется из установленного пакета, а не реализуется заново. Флажки отмены открытия и закрытия относятся к нашему приложению, а не к настройкам Bootstrap.

## Сборка и проверки

```sh
npm run build
npm run preview
npm test
npm run test:browser
```

`preview` раздаёт папку dist на порту 5174; не запускайте его одновременно с dev. Сборка включает CSS, JavaScript Bootstrap и его лицензию. После сборки preview работает без node_modules, но Node.js всё равно нужен.

В Windows браузерные тесты по умолчанию запускают установленный Microsoft Edge. На других платформах предварительно выполните `npx playwright install chromium`. Для Chromium в Windows задайте `$env:BROWSER_CHANNEL="chromium"` после установки браузера.
